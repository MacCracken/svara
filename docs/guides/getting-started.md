# Getting started with svara

## Build

```sh
cyrius deps                              # resolve dependencies
cyrius build src/main.cyr build/svara    # compile
cyrius test                              # run tests/*.tcyr
```

```sh
cyrius audit                 # the gate a PR must pass: fmt · lint · docs · tests · bench
./scripts/check-logging.sh   # the -D LOGGING gate — audit cannot pass defines
```

## Layout

- `src/` — 17 library modules plus `main.cyr`, a **smoke entry** that links them
  all and exercises the pipeline. It is not the consumption path.
- `tests/` — 22 `.tcyr` suites, auto-discovered by `cyrius test`.
- `benches/hotpath.bcyr` — 13 hot-path benchmarks (`cyrius bench`).
- `examples/` — 5 runnable programs; the readable introduction to the API.
- `dist/svara.cyr` — the distlib bundle consumers actually compile. Generated by
  `cyrius distlib`; **checked in**, so regenerate it when `src/` changes.
- `lib/` — vendored stdlib + dependency bundles. Do not edit; `cyrius deps` owns it.
- `rust-old/` — the original Rust, preserved read-only as the parity oracle.
  **Do not modify.** Scheduled for removal once a consumer is green
  ([roadmap](../development/roadmap.md) 3.7.0).

## Adding a feature

1. **Add or edit a library module** in `src/`, and add it to `[lib] modules` in
   `cyrius.cyml` so it reaches the bundle. `main.cyr` is the smoke entry — new
   code does not go there, though it should `include` the new module.
2. **Cross-check parity against the oracle**, and cite a **tag**, not a bare
   path, so the citation survives the directory's removal:
   `git show 3.5.2:rust-old/src/phoneme.rs`. Diverging from what the Rust did
   needs an ADR — see [ADR-0007](../adr/0007-reject-nan-formant-parameters.md)
   for the shape of that argument.
3. **Add tests** to `tests/<module>.tcyr` — `tests/svara.tcyr` is the smoke
   suite, not the place for module coverage. [testing.md](testing.md) has the four
   rules a new assertion has to follow, each learned from a real defect.
4. **Run `cyrius audit`**, then `./scripts/check-logging.sh`. Both are CI gates.
5. **Regenerate the bundle** — `cyrius distlib` — if you touched `src/`.
6. Bump `VERSION` (`./scripts/version-bump.sh X.Y.Z`) and add a CHANGELOG entry
   before tagging.

## Two things that will bite you

- **The bump allocator never frees.** Memory returns to the OS at process exit
  and nowhere else, so an allocation in a per-sample loop is unbounded growth,
  not a slow drift. Never allocate on the synthesis hot path.
- **Fallible calls return a negative `SVARA_ERR_*`, not a `Result`** — and
  pointer-returning ones signal failure with **0**. Test both; writing through a
  0 writes to address 0.

See [`../adr/template.md`](../adr/template.md) when a non-trivial design choice deserves an ADR.
